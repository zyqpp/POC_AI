# Skill: docs-quality-audit

Use this skill when auditing Markdown documentation quality.

## Responsibilities

Check whether documentation pages have:
- clear title,
- purpose,
- scope,
- owner or responsible role if available,
- status if available,
- links to related documents,
- screenshots or diagrams where useful,
- no broken relative links,
- no obviously outdated references,
- consistent headings.

## Do not

- Rewrite documentation unless asked.
- Change business meaning.
- Remove sections.
- Invent system behavior.

## Output

Report:
- missing sections,
- broken links,
- inconsistent structure,
- recommended fixes,
- files requiring human review.
