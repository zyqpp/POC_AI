# AI Documentation Index

Ten katalog zawiera dokumentację przygotowaną od zera dla agentów AI i zespołu projektowego.

- `AI_PROJECT_TREE.md` - struktura katalogów i plików.
- `AI_TECH_STACK.md` - stos technologiczny i komendy.
- `AI_ARCHITECTURE_HLD.md` - architektura wysokiego poziomu.
- `AI_DATA_MODEL.md` - model danych i główne tabele.
- `AI_DATABASE_STRUCTURE.md` - struktura baz danych: bazy, schematy, tabele, kolumny, relacje, skrypty SQL oraz mapa ekranów/procesów do tabel.
- `AI_API_INVENTORY.md` - spis endpointów API.
- `AI_DTO_MODELS.md` - DTO i kontrakty danych.
- `AI_CODE_NAVIGATION_GUIDE.md` - instrukcja ustalania faktów w kodzie.
- `AI_DOCUMENTATION_RECOMMENDATIONS.md` - rekomendowana dalsza dokumentacja.
- `AI_CODE_FACTS.json` - metadane zebrane skryptem dla agentów.
- `AOS_Template/` - szablon Analitycznego Opisu Systemu dla ekranów, menu i funkcji end-to-end.
- `AOS/orders/checkout-create-order/` - pierwszy przykładowy AOS: Checkout i utworzenie zamówienia.

Skrypty pomocnicze są w katalogu `../AI_Agent_scripts`.
