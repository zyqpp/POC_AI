# 06 PROCESY

## Dokumenty

- `PROCESY_END_TO_END.md` - lista procesów biznesowo-systemowych i ich ślad techniczny.
- `CHECKOUT_E2E.md` - pełny proces end-to-end dla wzorcowego checkoutu.
- `ORDER_DETAIL_LIFECYCLE.md` - pełny proces szczegółu zamówienia `/orders/:id`: odczyt, statusy, cancel, return, hold, notatki i reorder.
- `SHIPMENT_DETAIL_LIFECYCLE.md` - proces logistyczny `/shipments/:id` i `/orders/:id/tracking`: assignment, statusy, ops-state, retry, rating i outbox.
