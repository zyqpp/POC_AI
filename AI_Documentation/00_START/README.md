Ten katalog definiuje zasady odtworzenia dokumentacji od zera. Ma być czytany przed analizą systemu, API, modelu danych i AOS.

## Dokumenty

- `CEL_I_ZAKRES.md` - co dokumentujemy i czego świadomie nie robimy.
- `ZRODLA_PRAWDY.md` - dozwolone i zakazane źródła faktów.
- `KOLEJNOSC_PRACY.md` - kolejność pracy agenta dokumentacyjnego.
- `STANDARD_ATOMOWEJ_DOKUMENTACJI.md` - identyfikatory `E-*`, `P-*`, `A-*`, `ERR-*`, struktura katalogów i wymagany opis pól, akcji, błędów oraz testów.
