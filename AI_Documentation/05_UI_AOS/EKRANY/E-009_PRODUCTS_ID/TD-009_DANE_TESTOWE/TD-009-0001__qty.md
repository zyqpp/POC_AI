# TD-009-0001 Ilość Koszyka

Status: `potwierdzone`.

| Typ | Dane | Oczekiwany rezultat |
|---|---|---|
| min | `qty=product.minOrderQty` | `addToCart` dopuszcza i zapisuje do `CartStore` |
| wielokrotność | `qty=2 * minOrderQty` | zapis ilości bez korekty |
| poniżej min | `qty=minOrderQty - 1` | normalizacja do min albo [ERR-009-0002](../ERR-009_BLEDY/ERR-009-0002__minimum-order-quantity-is-p-minorderqty.md) |
| powyżej stocku | `qty=availableStock + minOrderQty` | [ERR-009-0003](../ERR-009_BLEDY/ERR-009-0003__only-p-availablestock-units-available.md) |
| brak zakupu | inactive albo `availableStock=0` | [ERR-009-0001](../ERR-009_BLEDY/ERR-009-0001__this-product-is-currently-unavailable-for-purchase.md) |
