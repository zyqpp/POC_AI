# P-009-0001 Order Quantity

Status: `potwierdzone`.

| Obszar | Opis |
|---|---|
| Typ UI | input number `[ngModel]="qty"` w sekcji Dealer `Add to Cart` |
| Wymagalność | wymagane tylko dla roli `Dealer` i tylko gdy `canPurchase()` jest true |
| Walidacje | `normalizeQty`: minimum `Products.MinOrderQty`, maksimum `maxPurchasable()`, krok `Products.MinOrderQty`, liczba całkowita |
| API/DTO | brak requestu API; akcja [A-009-0005](../A-009_AKCJE/A-009-0005__addtocart.md) zapisuje lokalny `CartStore` |
| Tabela SQL | `Products` tylko odczyt limitów |
| Kolumna SQL | `Products.MinOrderQty`, `Products.TotalStock`, `Products.ReservedStock`; `AvailableStock` wyliczone, zapis DB: `brak` |
| Dane Do Test | `TD-009-0001`: min, max, poniżej min, powyżej stocku, produkt inactive/out of stock |
| Testy | `TC-009-0003`, `TC-009-0004` |
