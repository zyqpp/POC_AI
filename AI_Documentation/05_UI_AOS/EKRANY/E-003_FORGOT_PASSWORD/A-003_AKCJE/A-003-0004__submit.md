## Opis Akcji

Akcja "Wyślij OTP" — submit formularza kroku `email`. Użytkownik klika przycisk "Send OTP" (lub "Continue"). Komponent wywołuje `sendOtp()`, który waliduje formularz i wysyła `POST /identity/api/auth/forgot-password` z emailem. Niezależnie od sukcesu lub błędu HTTP komponent przechodzi do kroku `reset` (step = 'reset') aby zawsze pokazać formularz OTP — to jest celowe (security through obscurity: nie ujawniamy czy email istnieje). Dla drugiego etapu (reset hasła) analogiczna akcja to `resetPassword()` wywoływana przez submit drugiego formularza.

## Diagram Przepływu

```mermaid
sequenceDiagram
    participant U as Użytkownik
    participant FE as ForgotPasswordComponent
    participant API as AuthApiService
    participant BE as AuthController
    participant DB as IdentityAuth DB

    U->>FE: Wpisuje email i klika "Send OTP"
    FE->>FE: sendOtp() — walidacja emailForm
    FE->>API: forgotPassword({ email })
    API->>BE: POST /identity/api/auth/forgot-password
    BE->>DB: INSERT OtpRecords (email, code, expiresAt)
    BE->>DB: INSERT OutboxMessages (PasswordResetRequested)
    BE-->>API: 200 { message }
    API-->>FE: next()
    FE->>FE: step.set('reset') — niezależnie od sukcesu/błędu

    U->>FE: Wpisuje OTP i nowe hasło, klika "Reset Password"
    FE->>FE: resetPassword() — walidacja resetForm
    FE->>API: resetPassword({ email, otpCode, newPassword })
    API->>BE: POST /identity/api/auth/reset-password
    BE->>DB: SELECT OtpRecords WHERE email AND code AND expiresAt > NOW()
    BE->>DB: UPDATE Users SET PasswordHash = bcrypt(newPassword)
    BE->>DB: DELETE OtpRecords
    BE->>DB: INSERT OutboxMessages (PasswordResetCompleted)
    BE-->>API: 200 { message }
    API-->>FE: next()
    FE->>FE: toast.success + router.navigate(['/login'])
```

## Przykład Żądania HTTP

Krok 1 — wysłanie OTP:
```http
POST /identity/api/auth/forgot-password
Content-Type: application/json

{
  "email": "dealer@example.com"
}
```

Krok 2 — reset hasła:
```http
POST /identity/api/auth/reset-password
Content-Type: application/json

{
  "email": "dealer@example.com",
  "otpCode": "123456",
  "newPassword": "NewPass1!"
}
```
